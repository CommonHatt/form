# FORM Store — магазин техники

Полная обновлённая версия магазина с **конфигуратором ПК** и **Trade-in**.

**[Скачать FORM_PC_TradeIn_FULL.zip (около 10 МБ)](https://github.com/CommonHatt/form/raw/refs/heads/main/FORM_PC_TradeIn_FULL.zip)**

## Что нового

- **Конфигуратор ПК:** выбор процессора, видеокарты, материнской платы, ОЗУ, накопителя, блока питания, охлаждения и корпуса; предварительная проверка совместимости и подсчёт цены.
- **Trade-in:** заявка с моделью устройства, датой покупки, первоначальной ценой (необязательно), дефектами, состоянием и фотографиями; предварительная оценка, просмотр заявок администратором.

Оценка Trade-in **демонстрационная** и не является рыночной офертой; фотографии не анализируются ИИ. Проверка совместимости комплектующих предварительная.

## Запуск (Windows и Ubuntu)

1. Скачай и распакуй **FORM_PC_TradeIn_FULL.zip**.
2. Открой папку **form-store** в VS Code.
3. Установи **Node.js 22+**.
4. Скопируй `.env.example` в `.env` и обязательно поменяй `SESSION_SECRET` и пароль администратора.
5. В терминале запусти:

```bash
npm install
npm run dev
```

6. Открой `http://localhost:3001`.

| Страница | Адрес |
| --- | --- |
| Каталог | http://localhost:3001 |
| Конфигуратор | http://localhost:3001/builder.html |
| Trade-in | http://localhost:3001/tradein.html |
| Админ-панель | http://localhost:3001/admin |

**Технологии:** Node.js, Express, SQLite, HTML, CSS, JavaScript. Open Server Panel для этой версии не нужен. Реальная оплата не подключена.

Исходная старая сборка сохранена в `form.zip`. Новый ZIP собирается из неё скриптом `build_form.py` через GitHub Actions; конфиденциальные файлы `.env`, базы пользователей и `node_modules` в сборку не включаются.
